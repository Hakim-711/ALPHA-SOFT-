# UI Guidelines

## اتجاه التصميم

واجهة ERP يجب أن تكون هادئة، دقيقة، سريعة، وواضحة. الجمال هنا يخدم تقليل الأخطاء، وليس الاستعراض.

## الألوان

- الأزرق: إجراءات أساسية وروابط.
- الأخضر: نجاح أو تحصيل أو رصيد جيد.
- الأصفر: تحذير أو انتظار.
- الأحمر: خطر أو تأخير أو حذف.
- الرمادي: معلومات ثانوية وحدود.

## الخطوط

- عنوان الصفحة: 24px تقريبًا.
- عنوان القسم: 18px.
- النص العام: 14px.
- الجداول: 13px أو 14px حسب الكثافة.

## القواعد

- زر أساسي واحد في كل منطقة عمل.
- لا تخف المعلومات المالية المهمة.
- لا تخلط العملات في رقم واحد.
- الحالات يجب أن تظهر كبادجات واضحة.
- الجداول يجب أن تدعم القراءة السريعة والفرز حيث يلزم.
- النماذج يجب أن تكون مقسمة إلى أقسام.

## POS

شاشة POS لها قواعد خاصة:

- أقل نص ممكن.
- أزرار كبيرة نسبيًا.
- اختصارات لوحة مفاتيح واضحة.
- إجمالي الفاتورة واضح دائمًا.
- الدفع والمبلغ المتبقي والباقي للعميل تظهر معًا.
